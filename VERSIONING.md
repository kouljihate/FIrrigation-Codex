# Versioning

Current version: `2.1.0`

## 2.1.0 — 2026-10-01

- Added a map-based sector editor showing all imported/project geometry layers.
- Added multi-sector selection, colour and coordinate editing, rename, split, merge, and staged removal.
- Added one validated batch confirmation that records a revision and clears dependent irrigation-design layers.

## 2.0.0 — 2026-10-01

- Published the initial public `FIrrigation-Codex` repository.
- Corrected meter-based irrigation calculations for rows, trees, driplines, pipes, and manifolds.

## Update Policy

- Record each user-requested project change in this file.
- Use a patch version for fixes, a minor version for backward-compatible features, and a major version for breaking changes.
- Commit and push the documented changes to the `codex` GitHub remote.
